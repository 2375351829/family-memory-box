## 二、帖子正文

### 一家人的团圆饭，为什么越来越安静

中秋国庆回家，饭桌上你肯定也见过这个画面：菜很丰盛，人很齐全，但每个人都在刷手机。不是不想聊，是不知道从哪儿聊起——「最近怎么样」「吃了吗」这几句话，问不出口，也答不出新意。

所以我给这次活动做的假期小工具，是一个**「家庭回忆话题盒子」**：打开网页，抽一个话题，全家开始聊；聊出来的故事、翻出来的老照片，随手存进去，最后能汇成一本给爸妈的回忆录。

### 它是怎么玩的

整个流程就三步：**抽题 → 讲述 → 成册**。

**第 1 步，抽题。** 盒子里有 6 大分类 × 8 题，共 48 个话题，每个话题还配了 2 条追问，一共 96 条。话题不是「你有什么爱好」这种尬聊题，而是「小时候做过最调皮的一件事是什么」「撒过最离谱的一个谎是什么」这种一抛出来全家就绷不住的题。

**【替换图片 2：上传 发帖图片-Images/03-抽题盒子-topic-box.png】**

抽题还有个小仪式感：开题道具是**节日专属**的——国庆打开是能转的五星描金转盘，指针停在哪一题就聊哪一题；中秋是掀月饼盒、春节是拆红包、端午是剥粽子，27 个节日各有各的开题动作。

**【替换图片 3：上传 发帖图片-Images/g1-抽题动效-draw.gif】**

**第 2 步，讲述。** 抽到题后不要急着让长辈回答，先由追问带着往下聊：「当时几岁？」「现在想想该打几分？」长辈讲故事的时候，用语音输入把故事记下来，再翻出手机里的老照片传上去。

### 几个设计上的小心思

**手机扫码即开。** 部署后会自动探测局域网地址并生成二维码，长辈用手机扫码就能打开，不需要装任何 App。全家人围坐时，一人一个手机就能参与。

**【替换图片 8：上传 发帖图片-Images/10-移动端-mobile.png】**

**27 个节日的专属主题。** 内置 27 个传统与现代节日的主题系统：春节有祥云画卷、国庆有转盘道具、端午有龙舟配色，到什么节自动换什么节的样子。这次中秋国庆档期打开，首页就是双节的水墨画卷。

**中国风视觉。** 全局毛玻璃质感 + 书法字体标题 + 描金描边 + 回纹、四角云纹等传统纹样，PC、平板、手机三端适配，最窄适配到 390×844，无横向滚动。

**数据不出家门。** 这是给家庭用的工具，所以它只在家庭内网跑：所有故事、照片都存在自己设备上，不依赖任何云服务，不上传任何第三方。

### 技术实现

- **双栈实现**：Python Flask + SQLite 与 Node.js + Express 两套后端功能完全等价，NAS 上哪个环境顺手用哪个；
- **22 个 API 端点**，前后端按契约开发；
- **123 个自动化测试全部通过**：单元测试 37 个、集成测试 81 个、E2E 测试 5 个（Playwright 驱动真实浏览器跑通核心流程）；
- **Docker 一键部署**：针对群晖、fnOS 等 NAS 做了部署适配，健康检查、数据目录与代码分离、JSON 一键备份恢复、日志轮转都内置了；
- **视觉素材全部手绘 SVG**：节日画卷、转盘道具、中国风插画都是矢量文件，无版权风险、离线可用、加载快。

### 用 TraeCode 做它是种什么体验

整个项目从 0 到现在，全程在 TraeCode 里协作完成。印象最深的几点：

- **出题式开发真的可行**：需求先聊清楚，再拆任务、列清单、按计划推进，AI 不是「一次性吐代码」，而是能跟着计划走完全程；
- **测试不是摆设**：让 AI 自己写测试、跑测试、修到全绿，改坏什么立刻能发现。这次转盘动效拆两层结构、话题判重逻辑等好几处问题都是测试先揪出来的；
- **细节也能反复磨**：标题文案改了 27 个节日的专属版本、二维码同步真实局域网地址、转盘只转盘面不转指针——这类需求用自然语言描述清楚就能落地。

### 想试试的话

源码和部署手册都整理在项目里：Docker 部署 5 步搞定，README 写好了从上传到启动的每一步（含群晖/fnOS 的权限坑位说明）。仓库地址整理好后会在评论区放出，想先看效果的可以留言。
